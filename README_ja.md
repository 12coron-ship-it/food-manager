# Stock Manager (v202606092126)

Stock Manager（ストックマネージャー）は、食材だけでなく、トイレットペーパーなどの日用品や掃除用の洗剤、各種調味料など、生活に必要なあらゆる「ストック」を一元管理して無駄遣い・フードロスを防止するための、美しくモダンなWebアプリケーションです。

---

## ✨ 主な機能

1. **直感的なタブインターフェース**:
   - **ストック（在庫）**: 登録された食材や日用品を、消費期限アラート、カテゴリー、保存場所（冷蔵・冷凍・常温）とともに一覧表示します。残量のワンタップ変更（100%〜0%）にも対応しています。
   - **調味料**: 基本的な調味料の残量を管理します。残量ボタンをタップしてレベルを変更でき、0%から100%に戻した際には、スペア（在庫数）から自動的に1つ差し引かれます。
   - **買い物リスト**: カテゴリーごとに分類されたチェックリストです。自動入力、数量・単位の指定、在庫切れ調味料の「買い足し自動推薦チップ」を備えています。
   - **履歴と廃棄分析**: 使い切った（消費）食材と、無駄にしてしまった（廃棄）食材を記録し、週・月・年単位での廃棄率や、カテゴリーごとの廃棄割合を円グラフで視覚化します。

2. **スマートな予測入力・自動判定**:
   - 食材名を入力するだけで、よくある食材データベースから自動的にカテゴリー、保存場所、標準消費日数、デフォルトの単位・数量を予測し、自動セットします。

3. **スムーズなタブスワイプ切り替え**:
   - タッチデバイスにおいて、左右スワイプで非常に快適にタブを切り替えられます。ボタン、入力欄、セレクトボックス、水平スクロールリスト（おすすめチップ）上の操作は除外するよう調整され、誤作動を防ぎます。

4. **プレミアムなデザインテーマ**:
   - **オーガニック**（デフォルトのグリーン系）、**ハニー**（琥珀・アンバー系）、**ミント**（ティール系）、**ベリー**（ピンク系）、**ライト**、**ダーク**の6つの洗練されたカラーテーマを提供します。

5. **日本語・英語の多言語対応**:
   - 設定からいつでも瞬時に「日本語」と「English」を切り替えられます。言語設定は `localStorage` に自動保存され、再起動後も保持されます。

6. **データのポータビリティ**:
   - JSON形式での全データバックアップ・復元（JSONインポート / エクスポート）。
   - Excel等で直接閲覧・編集できるCSVエクスポート機能。

## 🚀 起動方法

1. プロジェクトフォルダ内にある `index.html` ファイルをブラウザで開く（ダブルクリックなど）だけで起動できます。
2. ローカルサーバー（VS CodeのLive Server機能や、Node.jsの `npx serve .` など）を利用すると、より快適に動作を確認できます。
3. Windows環境では、同梱の `start_app.bat` を実行するだけで自動的にアプリケーションがブラウザで起動します。
